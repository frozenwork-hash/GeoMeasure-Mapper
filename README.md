# GeoMeasure (Mapper)

A PyQt6 application for working with map materials, calculating distances, calibrating scales, and exporting measurement data.

## Features
- Load raster map images and multi-page PDF documents.
- Scale calibration using a reference segment.
- Interactive point placement, route building, and automatic distance calculation.
- Interactive compass overlay and customizable coordinate grid.
- Modular data export to PNG, PDF, CSV, and JSON formats.

## Building and Running from Source

   ```bash
   git clone [https://github.com/frozenwork-hash/GeoMeasure-Mapper.git](https://github.com/frozenwork-hash/GeoMeasure-Mapper.git)
   cd GeoMeasure-Mapper

2. Install dependencies:
   ```bash
   pip install -r requirements.txt

3. Run the application:
   ```bash
